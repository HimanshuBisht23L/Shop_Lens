You are an expert Principal Software Architect and Senior Infrastructure Engineer. Your task is to generate an exhaustive, production-grade, 0-to-100 Master Engineering & Architecture Roadmap file named `ROADMAP.md` for a hyperlocal commerce SaaS platform called **ShopLens**.

---

### 🎯 1. PROJECT CONTEXT & REAL-WORLD PROBLEM STATEMENT
* **Real-World Problem**: Physical shoppers waste time and fuel traveling 5 km to a local brick-and-mortar store, only to discover the item they want is **out of stock**.
* **ShopLens Solution**: A multi-tenant hyperlocal commerce SaaS platform that allows customers to check live physical store stock, prices (₹ INR), navigation distances, and photos within a 5 km radius from home *before* leaving their room.
* **User Roles**:
  1. **Customer (Shopper)**: Uses GPS spatial radius search, fuzzy keyword search, and AI semantic vector search to locate in-stock items.
  2. **Shopkeeper (Merchant)**: Publishes inventory, uploads camera photos (compressed to WebP with BlurHash), and imports bulk CSV spreadsheets (processed via background workers).
  3. **Platform Admin**: Monitors system telemetry, store counts, background job status, and AI model inference latency (~14ms).

---

### 🛠️ 2. REQUIRED TECHNOLOGY STACK
* **Frontend**: Next.js 16 (App Router), React 19, Tailwind CSS, Lucide React, Framer Motion, Axios.
* **Backend API**: FastAPI (Python 3.11), Uvicorn, Pydantic v2, SQLAlchemy (Asyncio), Asyncpg.
* **Database**: PostgreSQL 16 + PostGIS Extension (`geography` type, `ST_DWithin` spatial distance) + `pg_trgm` Extension (GIN fuzzy text index).
* **Media & Storage**: MinIO (S3 Compatible), Pillow (PIL WebP compression `quality=85`), BlurHash.
* **Background Queue**: Redis 7 + ARQ (Async Redis Queue) background task workers.
* **AI / ML Engine**: PyTorch, HuggingFace `sentence-transformers/all-MiniLM-L6-v2` (384-dimensional vector embeddings), `scikit-learn` / `XGBoost` custom demand forecasting models (`.pkl` export).
* **Infrastructure**: Nginx Load Balancer, Docker Compose multi-network VPC simulation (`frontend_net`, `backend_net`, `storage_net`), grafana, prometheus, alertmanager, loki.
